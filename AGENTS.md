# Repository instructions

- Never add Codex, Anthropic, or other AI attribution trailers to commits.
- Never print, commit, or copy `.env` or credentials into worktrees. Configuration examples contain empty values only.
- Source-project branding, proprietary product names, and local source paths must not appear in application identifiers, UI, or tracked documentation. Preserve legally required third-party license notices.
- Build genuine functionality. Do not report mock data, stub integrations, browser speech synthesis, or browser transcription as the requested local voice engine.
- All external email and phone dispatch requires a reviewed, content-bound approval. No live outreach during development.
- Phone integration is deferred; absent carrier credentials must not block the browser voice demo.
- Commit only tested changes. Report checks actually run and unresolved dependencies.

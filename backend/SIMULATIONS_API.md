# Exploratory future simulations

`POST /api/simulations` accepts `{company_id}` and returns a saved, source-backed exploratory report (201). `GET /api/simulations` lists recent reports, optionally filtered by company_id. `GET /api/simulations/{run_id}` loads the saved result. `GET /api/simulations/options` offers a bounded list of recently researched sellers. All routes require authentication; writes retain the normal CSRF protection.

The service screens up to 250 sourced, non-excluded buyer profiles, excludes self-matches and rejected evidence, and reports how many profiles were evaluated or omitted. It sends bounded evidence per field to the configured fast model. A second, smaller review uses original excerpts to challenge unsupported sector, geography, investor-type and size inferences. Every saved recommendation must reference the selected seller and buyer's actual business evidence. IDs, source URLs, excerpts and review labels come from stored records, not the model. Reference validation is deterministic; semantic interpretation remains a model hypothesis requiring review.

Runs retain a private immutable snapshot of inputs, facts, owner conditions, active mandates and sources. Public responses omit the large internal snapshot, but include each recommendation's citations. Three explicit hypothetical owner branches reuse the existing deterministic constraint evaluator: full sale, retain 25%, preserve the team. These do not modify owner preferences or create mandates. Missing mandate terms remain unknown; source-backed public fit never proves current buyer interest. Model rankings may vary across runs.

Missing seller research or sourced buyers returns 409 with an actionable error. Model timeout/unavailability or invalid output returns 503 without saving a successful run. The model calls have 60- and 40-second limits. Empty supported results are saved honestly, and invalid recommendations are counted. No run sends outreach or creates contact approvals.
